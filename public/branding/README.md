# Daily Time Keeper Brand Assets & Splash Animation Folder

This directory contains the official brand identity assets, logos, and splash screen animation specifications for Daily Time Keeper.

## Files in this Folder

1. **`tickr-logo.svg`**: Official vector format of the 3D-styled Tickr timekeeper emblem. Scalable to any resolution without loss of clarity.
2. **`tickr-logo.jpg`**: High-resolution raster emblem with 3D gradient ribbon and soft drop-shadow.
3. **`splash-animation.json`**: Animation timelines, keyframes, progress checkpoints, and timing parameters for the startup splash screen.

## Access in Application

You can also browse, interact with, test, and download these assets directly inside the **Settings Tab** (`Brand Assets & Media` folder section) of the app.
